Command Dictionary

Survival Guide

¿Qué es la Terminal?

Es una interfaz de texto para hablar directamente con el ordenador sin usar el ratón.

El Prompt

El texto user@mast-lab:~$ indica que el sistema está listo para recibir órdenes. El símbolo ~ representa tu directorio personal.

Sintaxis Básica

comando [argumentos]
Ejemplo: cd /var/log

Rutas: Absolutas vs Relativas

Las rutas absolutas empiezan desde la raíz (ej: /var/log). Las relativas desde donde estás (ej: .. para subir de carpeta o archivo.txt).

Caza de Procesos

Usa ps aux para listar todos los procesos en ejecución. Localiza el PID (número identificador) y destrúyelo con kill -9 PID.

Permisos de Ejecución

Los scripts suelen necesitar permisos especiales para ejecutarse. Usa chmod +x script.sh para volverlo ejecutable, y lánzalo con ./script.sh.
